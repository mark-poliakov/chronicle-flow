# Checks: what do git-hooks and CI run

Перелік перевірок — що саме мають запускають хуки і CI.

## Git-hooks

### Pre-commit hook

Перед кожним комітом має запускатися:

- Перевірка форматером (або перевірка --check, або виправлення --write - обидві опції допускаються)
- Перевірка лінтером (тільки з файлами, що містять код: .md, .json та файли подібного формату не перевіряються)
- Збірка (`npm run build`)
- Unit-тести (`npm run test`; якщо тести ще не написані - пропустити)

## CI

Автор ще не знає тему CI/CD достатньо добре, щоб вказати точний перелік перевірок CI. Цей розділ виправлятиметься чи доповнюватиметься в майбутньому.

Перевірки CI:

- unit-тести - 'на кожному push'
- інтеграційні тести - 'на кожному PR'
- всі тести (unit, інтеграційні, e2e) + _можливо_, мутаційне тестування - 'nightly'
