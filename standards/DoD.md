# Definition of Done

Умови, за яких PR можна зливати у головну гілку (main).

PR можна зливати у головну гілку, якщо:

- PR покриває логічно окреслену частину проекту (напр., створення тестів, створення фронтенду, виправлення помилки у 'fix/...' гілці)
- Нові елементи фронтенду тестувалися вручну, тестувалися вручну непокриті автоматичними тестами нові частини бекенду

Не можна зливати PR у головну гілку, якщо:

- PR має некоректну назву (див. стандарти назв комітів Commit Messages у `./git-workflow.md`)
- Новий код жодного разу не запускався
- PR не покриває окреслену частину проекту (напр., два-три коміти до 10 рядків коду разом, не пов'язаних логічно)
