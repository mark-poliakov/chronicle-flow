# Архітектура проєкту Chronicle Flow

## 1. Загальний огляд системи
Система є монорепозиторієм, який складається з двох основних частин:
- **Client (`/client`):** Single Page Application (SPA) на базе React + Vite + TypeScript.
- **Server (`/server`):** REST API на базі Nest.js + TypeScript + PostgreSQL (Prisma ORM).

## 2. Концепція ретроспективних правок (Core Domain Logic)
Головна фіча щоденника — збереження історії модифікацій записів. 
- **Основна сутність (`Entry`):** Містить метадані (ID, автор, календарна дата, до якої належить запис).
- **Сутність версій (`EntryRevision`):** Текст запису **ніколи не перезаписується «вручну» безслідно**. Кожна зміна або доповнення створює новий запис ревізії з міткою часу (`created_at`).
- При відображенні клієнт отримує як поточний зведений стан запису, так і таймлайн його правок («Оригінал від 10 жовтня», «Доповнення від 12 жовтня»).

## 3. Модульна структура Бекенду (`/server`)
Бекенд побудований за принципами **Domain-Driven Design (DDD)** та модульності Nest.js:

1. **`AuthModule`**:
   - Обробка реєстрації, входу, видачі JWT-токенів.
   - Хешування паролів (bcrypt).
2. **`UsersModule`**:
   - Управління профілем користувача та його налаштуваннями.
3. **`EntriesModule`** (Центральний модуль):
   - **`EntriesController`**: Приймає HTTP-запити від фронтенду.
   - **`EntriesService`**: Містить бізнес-логіку обчислення версій та створення нових ревізій.
   - **`DTOs` (Data Transfer Objects)**: Сувора валідація вхідних даних за допомогою `class-validator`.
4. **`TimelineModule`**:
   - Формування календарної сітки (агрегація днів, де є записи, для швидкого рендерингу на фронтенді).

## 4. Структурна організація Фронтенду (`/client`)
Фронтенд використовує популярну та зрозумілу структуру **Feature-based architecture** (організація за фічами, а не просто за типами файлів):

- **`src/components/ui/`**: Перевикористовувані атомарні UI-елементи (Кнопки, Інпути, Модальні вікна).
- **`src/features/auth/`**: Форми входу/реєстрації, контекст авторизації.
- **`src/features/diary/`**:
  - `components/CalendarGrid.tsx`: Календарна сітка.
  - `components/EntryEditor.tsx`: Редактор записів з можливістю вибору «ретроспективної» дати.
  - `components/RevisionHistory.tsx`: Відображення історії змін (хронологічна стрічка).
- **`src/services/`**: Модуль для роботи з API (Axios / Fetch), типізовані запити до Nest.js.
- **`src/types/`**: Спільні TypeScript інтерфейси для клієнтської частини.
