# Diary Feature

## 1. CalendarView:

- **Основне**: дозволяє обрати дату
- Візуально відображає дні місяця
- Візуально маркує дні: чи є там запис, ***\*backlog\*:***чи містить "доповнення з майбутнього" базуючись на даті створення записів

## 2. Diary:

### 2.1. EntryView:
- Відображає всі записи за обраний день з відображенням дати створення кожного, із можливістю редагування/видалення кожного з них.

### 2.2. RevisionHistory:
- Показує користувачеві історію життя конкретного дня
