# Diary Feature

## 1. CalendarView:

- **Основне**: дозволяє обрати дату
- Візуально відображає дні місяця
- Візуально маркує дні: чи є там запис, чи він оригінальний, чи містить "доповнення з майбутнього"

## 2. Diary:

### 2.1. EntryView:
- Відображає запис за обраний день з помітками (наприклад, кольором), якщо різні частини були написані в різні дні

### 2.2. RevisionHistory:
- Показує користувачеві історію життя конкретного запису
