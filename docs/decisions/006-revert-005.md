# Return to using precommit-hooks

## Context and Problem Statement

Fist lab work requires precommit-hooks set up. Giving up on them because of lack of experience and desire to study them is unacceptable.

## Considered Options

- Configure formatters, linters and build for precommits
  - pros: gaining skill and knowledge during configuring
  - cons: time consumption, much effort required
- Keep as is
  - pros: saved time to spend of other activities
  - cons: first lab is likely to be rejected again; the configuration of precommits is only delayed - it is to be done some day

## Decision Outcome

Chosen option: "Configure formatters, linters and build for precommits", because the author wants the first lab to be completed. Also delaying gaining such a skill is not a good idea, especially when having a good opportunity - learning project. The decision number 005 is reverted.
